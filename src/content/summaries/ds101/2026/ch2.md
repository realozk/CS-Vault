# Ch 2: Introduction to Data Structures and Algorithms

What a data structure is, ADTs, and how we classify them

---

* A data structure is the organization of data in a computer's memory (or on disk) so it can be used efficiently.
* An Abstract Data Type (ADT) defines WHAT operations a structure supports (e.g. push/pop), not HOW they are implemented.
* Primitive data structures (int, char, float, boolean...) are built directly into the language.
* Non-primitive data structures (arrays, lists, stacks, trees, graphs...) are built using primitive types and have relationships between elements.
* Linear data structures arrange elements sequentially, each element (except first/last) having exactly one predecessor and successor — e.g. arrays, linked lists, stacks, queues.
* Non-linear data structures arrange elements hierarchically or in a non-sequential way — e.g. trees and graphs.
* Reusability is the ability to use an already-implemented data structure again in different programs/places without rewriting it.
* Common operations across data structures: traversal, insertion, deletion, searching, sorting, merging.
* An algorithm is a finite, well-defined sequence of steps to solve a problem; good algorithms are evaluated on correctness, time efficiency, and space efficiency.
