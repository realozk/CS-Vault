## Evolution of the Internet and the Web

The **Internet** is a global network of interconnected networks. Its foundations include **ARPANET**, a US Department of Defense project connecting academic and military networks, and the **TCP/IP** protocol suite.

The Internet expanded rapidly in the 1990s with the **World Wide Web**, created by Tim Berners-Lee to provide hypertext and a graphical way to access information. Email became a major communication tool, and e-commerce began to grow.

An **intranet** is a private organizational network. An **extranet** securely makes selected organizational information available to external partners.

## Web standards and accessibility

- **IETF** (Internet Engineering Task Force) and **IAB** develop and guide Internet protocols.
- **ICANN** coordinates domain names and IP addresses.
- **W3C** (World Wide Web Consortium) develops Web standards, including HTML, CSS, and accessibility guidance.

**Accessibility** means designing websites to accommodate people with visual, auditory, physical, and neurological disabilities. The **WAI** and **WCAG** provide guidance, while laws such as the ADA and Section 508 address accessibility requirements.

**Universal design** aims to make products and environments usable by everyone without requiring adaptation.

## Networks and the client/server model

A network connects computers so they can communicate and share resources. A **LAN** covers a local area; a **WAN** spans a wider geographical area.

In the client/server model, a **client** such as a web browser requests a service, page, or file. A **server** fulfills the request and sends the result over the network.

## Internet protocols

Protocols define how clients and servers communicate:

- **FTP (File Transfer Protocol):** exchanges files between computers; developers have commonly used it to upload websites.
- **HTTP (Hypertext Transfer Protocol):** exchanges web resources such as text, images, and multimedia.
- **SMTP, POP3, and IMAP:** SMTP sends email; POP3 and IMAP retrieve it.
- **MIME:** extends email to support multimedia and attachments.
- **TCP/IP:** the Internet's core communication protocol suite. TCP divides data into packets and supports reliable delivery; IP routes packets to their destination addresses.

## URIs and domain names

An **IP address** uniquely identifies a device on a network. A **domain name** is a human-readable name for an Internet resource, and the **DNS (Domain Name System)** translates domain names into IP addresses.

A **URL (Uniform Resource Locator)** is a type of **URI (Uniform Resource Identifier)** that identifies a resource's location. A URL can contain a protocol, domain name, folder, and file name.

**Top-level domains (TLDs)** are the rightmost part of a domain name, such as `.com`, `.org`, and `.edu`. Country-code TLDs include `.sa` and `.uk`.

## Markup languages

Markup languages use tags to describe document structure and presentation:

- **SGML:** a standard for defining markup languages.
- **HTML:** the standard markup language used to structure web pages.
- **XML:** a language for describing and exchanging structured data.
- **XHTML:** combines HTML conventions with XML's stricter structure.
- **HTML5:** the modern HTML standard and successor to HTML4/XHTML.

## Popular web trends

The lecture highlights e-commerce, mobile access, blogs, wikis, social networking, RSS, podcasts, and cloud computing as popular uses and trends of the Web.
